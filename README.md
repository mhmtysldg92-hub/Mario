# Mario

Tarayıcı üzerinden oynanan, telefon destekli, klasik Super Mario tarzı platform oyunu. Tek dosya (`index.html`), harici bağımlılık yok.

## Oynanış
- Klavye: ← → veya A/D hareket • Z / Space / ↑ zıpla • X / Shift koş • Enter başlat
- Mobil: ekranda ◀ ▶ butonları + A (zıpla) + B (koş), tam ekran ve ses butonları
- Düşmanları üstüne zıplayarak ez, soru bloklarından coin çıkar, mantar ile büyü, büyüyünce tuğlaları kır, bayrak direğine ulaş

## Çalıştırma
`index.html` dosyasını tarayıcıda açmanız yeterli (sunucu gerekmez):
```
# isterseniz yerel sunucu
python3 -m http.server 8000
```
